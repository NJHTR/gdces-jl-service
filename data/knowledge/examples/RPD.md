1. 系统概述

1.1 系统定位

本系统面向建筑工程监理行业，为现场监理人员提供一套覆盖"记录—识别—文书—台账—协同"全流程的智能辅助工具。系统支持 AI 眼镜端、手机浏览器端、Web 管理端三端协同工作，核心目标是将监理日常工作数字化、智能化，减少手工填表工作量，提升现场监管效率。

3. 工作台

3.1 功能说明

工作台是用户登录后的首页，集成了智能监理助手和工作统计概览。

3.2 智能监理助手

对话框形式：用户通过文字或语音输入指令，系统返回回复或执行跳转

指令路由：系统内置指令匹配表，支持以下自然语言指令：

图片识别：用户可在输入框插入图片，配合自然语言指令（如"识别一下这张图的隐患"），系统将图片和指令一起发送给 AI 进行隐患识别

模型选择：用户可在底部工具栏选择使用的 LLM 模型

知识库选择：用户可选择关联的知识库（省统表 / 安全监理用表 / 知识图谱）

未匹配指令：当输入的指令不在路由表中时，系统调用 LLM 进行自由问答

3.3 工作统计概览

在工作台底部展示各类工作记录的"未查看"和"未处理"数量

统计范围按项目维度，覆盖：巡视、验收、旁站、见证、其他工作

展示安全隐患待处理数量

点击统计卡片可跳转到对应记录列表

3.4 层级导航

面包屑导航显示当前所处层级（如"工作记录 > 验收记录 > 新建"）

用户通过指令或点击操作逐级进入

4. 工作记录管理

4.1 记录类型

系统支持四种监理工作记录，每种记录有独立的表单字段和工作流程：

4.2 记录状态流转

草稿 → 已提交 → 已审批 → 已归档
                ↓
             已驳回

草稿：新建后的初始状态，可编辑修改

已提交：提交后等待审批

已审批：审批通过

已驳回：审批不通过，退回修改

已归档：最终归档状态

4.3 巡视记录

4.3.1 业务流程

监理人员进入施工现场

新建巡视记录，填写施工区域、位置、施工内容、天气

现场拍照（照片自动添加水印：项目名称、单位工程、施工区域、施工内容、拍摄时间、天气）

可补充巡视备注

提交巡视记录

4.3.2 照片水印要求

巡视照片必须包含以下水印信息：

项目名称

单位工程

施工区域

施工内容

拍摄时间（精确到秒）

天气

4.4 验收记录

4.4.1 业务流程

选择验收类型（如钢筋验收、混凝土验收、模板验收等）

系统根据验收类型从知识图谱中获取验收指引（步骤、要点、常见违规、规范依据）

填写施工区域、位置、验收内容

系统自动生成省统表验收记录文书

记录验收结果（合格 / 不合格 / 待整改）

4.4.2 验收指引内容

每种验收类型包含以下指引信息：

验收步骤：如钢筋验收包含"材料进场验收 → 钢筋加工检查 → 钢筋连接检查 → 钢筋安装检查 → 隐蔽工程验收"

检查要点：如"钢筋型号规格、间距、保护层厚度、搭接长度、锚固长度"

常见违规：如"钢筋型号不符、间距偏差超标、保护层不足、搭接长度不够"

规范依据：如"GB 50204 混凝土结构工程施工质量验收规范"

4.5 旁站记录

4.5.1 业务流程

新建旁站记录，填写旁站工程名称、旁站部位

系统自动记录开始时间

旁站过程中填写旁站情况描述

旁站结束时填写旁站结论

系统自动记录结束时间并提交

4.6 见证记录

4.6.1 业务流程

新建见证记录，填写材料名称、规格型号、施工区域、位置

拍照记录取样过程（见证照片）

提交见证记录

4.7 通用操作

查看列表：按记录类型、状态筛选查看

查看详情：查看记录完整信息

编辑：仅草稿状态可编辑

提交：草稿状态可提交

标记已查看：将记录标记为已查看，影响工作台统计

统计：按项目维度统计未查看和未处理数量

5. 安全隐患识别与整改闭环

5.1 业务场景

监理人员在现场发现安全隐患时，拍照上传，系统通过 AI 视觉模型自动识别隐患类型和风险等级，生成隐患记录和整改通知单，跟踪整改过程直到闭环。

5.2 隐患识别

5.2.1 识别方式

拍照识别：通过 AI 眼镜端、手机浏览器端或 Web 管理端上传照片

自然语言辅助：用户可附加自然语言指令（如"重点检查脚手架"），AI 结合指令进行识别

批量识别：现场识别页面支持多张图片批量识别

5.2.2 AI 识别返回结果

5.3 隐患记录管理

5.3.1 隐患状态流转

已提报 → 已通知整改 → 整改中 → 待复查 → 已闭环
                                    ↓
                               驳回整改

5.3.2 隐患记录字段

AI 识别结果（风险状态、类别、主要风险、证据、复查建议等）

关联影像（隐患照片路径、整改后照片路径）

关联文书（整改通知单 ID）

位置信息（施工区域、具体位置）

备注

创建时间、更新时间

5.4 整改闭环流程

1. AI 识别隐患 → 自动创建隐患记录（状态：已提报）
2. 监理确认 → 生成安全隐患整改通知单（状态：已通知整改）
3. 施工单位整改 → 提交整改后影像（状态：待复查）
4. 监理复查：
   - 通过 → 隐患闭环（状态：已闭环）
   - 不通过 → 驳回整改（状态：驳回整改）

5.5 安全隐患整改通知单

根据隐患自动生成，包含：隐患描述、证据、复查建议、施工区域、位置、隐患照片、监理人员、整改期限

整改通知单需总监签发

可导出 PDF

6.2 模块分类

按照交互层级分为两大类：

6.2.1 工作记录

6.2.2 安全隐患

6.3 操作流程

通过摄像头拍照或点击"导入图片"按钮选择本地图片

7. 监理文书管理

7.1 文书类型

系统支持 8 类监理文书的生成和管理：

7.2 文书状态流转

草稿 → 待审批 → 已审批 → 已归档
          ↓
       已驳回

草稿：新建后的初始状态，可编辑

待审批：提交审批后（仅需签发文书类型）

已审批：总监审批通过

已驳回：总监驳回

已归档：直接归档（不需要签发的文书类型提交后直接归档）

7.3 文书生成方式

7.3.1 手动创建

用户选择文书类型，填写标题和内容

系统自动填充基础字段：文书编号、日期、时间、监理人员、监理级别、施工区域、位置、天气

7.3.2 LLM 智能生成

用户提供文书类型、标题、隐患信息（可选）、巡检信息、额外上下文

系统调用 LLM 自动生成文书正文内容

生成后创建文书草稿，用户可进一步编辑

7.3.3 验收记录自动生成

创建验收记录时自动生成省统表验收记录文书

包含验收指引步骤、检查要点、常见违规、规范依据

7.4 监理日志自动生成

7.4.1 生成规则

选择日期后，系统自动聚合当日所有工作记录和安全隐患，按以下模块生成监理日志：

7.4.2 日志内容

项目名称、日期、星期

监理人员姓名和级别

天气信息

施工进展、监理工作、存在问题、其他事项

7.5 文书操作

创建：手动创建或 LLM 生成

编辑：仅草稿状态可编辑，支持语音补充内容

提交审批：提交后进入审批流程

审批通过：仅总监可操作

驳回：仅总监可操作

导出 PDF：生成 PDF 文件

下载 PDF：下载已生成的 PDF 文件

8. 信息库（知识检索与知识图谱）

8.1 知识库检索

8.1.1 知识库内容

系统内置两套知识库文档：

省统表（25 类）：

法定代表人任命书、质量终身责任书、总监任命书、总监变更申请书、总代授权书、项目印章使用授权书、驻场人员通知书、驻场人员调整通知书、监理规划、监理细则、监理审查表、工程开工令、暂停令、旁站记录、平行检查记录、巡视记录、监理通知单/回复单、会议纪要、工程变更台账、材料台账、监理日志、监理月报、质量事故监理报告、监理工作联系单、监理档案移交目录

安全监理用表（12 类）：

监理单位管理人员签名笔迹备查表、安全监理危险源控制表、安全监理日志、施工安全监理周报、建筑施工起重机械安装拆卸监理检查记录表、危险性较大的分部分项工程监理巡视检查记录表、安全监理工作联系单、安全隐患整改通知、安全隐患整改通知回复、暂时停止施工通知、复工申请、安全监理重大情况报告

8.1.2 检索功能

关键词检索：按文档名称关键词搜索

内容检索：按文档内容匹配搜索

分类筛选：按规范分类筛选

文档下载：下载原始文档文件

8.1.3 规范库维护

支持导入规范文档（docx / xlsx / pdf / doc / xls）

支持批量导入

导入的文档保存到知识库对应分类目录

8.2 验收指引

根据关键词（如"钢筋""混凝土""模板"）获取验收流程指引

指引内容包含：验收步骤、检查要点、常见违规、规范依据

支持通过 LLM 增强生成更详细的指引

8.3 LLM 智能问答

用户输入问题（如"钢筋搭接长度规范要求是多少？"）

系统先检索知识库获取相关上下文

再调用 LLM 生成专业解答

返回答案和关联的检索结果

8.4 知识图谱

8.4.1 实体类型

8.4.2 关系类型

8.4.3 知识图谱功能

实体管理：新建、查询、搜索、删除实体

关系管理：新建实体间关系（自动创建不存在的端点实体）

图遍历：以某实体为中心，获取指定深度的子图，用于可视化探索

AI 抽取：通过 LLM 从文本中自动抽取实体和关系，存入知识图谱

批量导入：从知识库文件中批量提取文本，用 LLM 自动抽取实体和关系

统计信息：实体总数、关系总数、各类型实体数量

8.4.4 验收指引引用

验收记录可引用知识图谱中的验收流程实体

引用后自动获取该实体的验收步骤和要点

用于生成省统表验收记录文书

监理确认 → 生成安全隐患整改通知单（状态：已通知整改）
  ↓
总监签发整改通知单
  ↓
通知施工单位整改
  ↓
施工单位整改 → 提交整改后影像（状态：待复查）
  ↓
监理复查
  ├── 通过 → 隐患闭环（状态：已闭环）
  └── 不通过 → 驳回整改（状态：驳回整改）→ 返回整改

15.3 派单协同流程

总监/总代创建派单
  ↓
选择被指派人（专监/监理员）
  ↓
填写任务信息（标题、描述、类别、优先级、截止时间、地点）
  ↓
系统推送通知到被指派人
  ↓
被指派人查看任务
  ├── 接单 → 开始执行 → 完成（填写回执）
  └── 拒单（填写拒单原因）
  ↓
总监/总代查看完成情况
  ├── 确认完成
  ├── 催办（如超时未处理）
  └── 转派（如需更换执行人）

15.4 文书生成流程

触发文书生成
  ├── 手动创建 → 填写内容 → 自动填充基础字段
  ├── LLM 生成 → 提供上下文 → AI 生成正文
  ├── 验收记录 → 自动生成省统表
  └── 监理日志 → 选择日期 → 自动聚合当日记录
  ↓
文书草稿
  ↓
编辑完善（语音补充）
  ↓
提交审批
  ├── 需签发类型 → 总监审批 → 通过/驳回
  └── 不需签发 → 直接归档
  ↓
导出 PDF / 下载
