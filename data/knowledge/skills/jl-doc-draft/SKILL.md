# 出监理文书

## 先查依据

```
jl-tool search_standards '{"query":"连墙件 间距"}'
```

规范全文**不在工作区**：不要用 rg 去找 standards 文件（工作区里没有）。
只有 search_standards 会给你「条号 + 标准名 + 摘录」，引用也从这里来。

查到就把条号写进 `bases`；**查不到就说没查到，不许拿相近条文凑数**。
规范库目前很小（见 AGENTS.md 里的条数），搜一次没有就是没有，别换关键词反复搜。

## 再出稿

```
jl-tool create_doc_draft '{"projectId":"<项目>","kind":"监理通知单","obj":"4#楼东侧外架","fields":{"部位":"4#楼东侧外架"}}'
```

`create_doc_draft` 会写文件、提交、入库，一步到位。
**用 shell 手写 md 不算出稿** —— 用户看不到，等于没做。

## 缺字段怎么办

留空。系统会按 schema 标出「待补」，用户在手机上补。
**不要为了凑齐而追问** —— 监理员在工地上没空回答五连问，先出稿比问清楚更重要。

出稿前想自查就用 `jl-tool validate_doc`，它告诉你还缺哪些键。

## 工具怎么调

命令行，已在 PATH 里，直接调：

```
jl-tool <工具名> '<JSON 参数>'
jl-tool list          # 只想看清单时
```

不要去找它的实现（没有 python 模块，也不要 find），找一次白花二十几秒。
