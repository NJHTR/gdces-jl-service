# 用现场证据

## 三种证据在哪

```
jl-tool search_photos '{"projectId":"<项目>","q":"沟槽 开挖"}'
jl-tool search_records '{"projectId":"<项目>","query":"连墙件"}'
ls records/            # 项目工作区里的现场记录
cat records/photos.md  # 影像索引：sha · 部位 · 时间 · 一句话描述
```

## 怎么写进文书

- 照片写「附现场照片（部位 时间）」，不要把 sha 写进正文。
- 语音写转写后的原话要点，不要写「用户发了一段语音」。
- 引用历史记录要带日期，别写「之前查过」。

## 看完图要留一句描述

如果这轮看了现场图，把你看到的内容用一句话写进 `records/photos.md`：
部位 + 时间 + 看到什么。下一轮别人问「这个部位以前查过什么」就靠这句话。

一句话就够，不要复述整张图。
