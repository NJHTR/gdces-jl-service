# 真机验收清单（D2）

> 这一项只能在微信里真机点，我替你点不了。下面按「前置 → 逐项验 → 常见故障」写，
> 每一项都写清楚**应该看到什么**，以及看不到时先查哪。
> 静态自检：`python3 scripts/check-miniapp.py`（不需要开微信，先跑这个）

## 0. 前置（缺一样真机就会失败）

| 项 | 现状 | 要做的 |
|---|---|---|
API 地址 | `http://127.0.0.1:8081`（SSH 隧道，仅开发者工具） | 真机需 **https 域名** 指向服务器 8081 |
微信后台「服务器域名」 | 未配置 | request/downloadFile 合法域名加上这个 https 域名 |
隐私保护指引 | 未配置 | 勾选：位置信息（拍照水印）、相册/相机、麦克风（语音） |
手机网络 | — | 与服务器连通；隧道方案不适用于手机 |

## 1. 打开小程序（先看会不会白屏）

- 应该看到：首页（项目名、今日记录数、「AI 监理」入口）
- 白屏 → 看 `check-miniapp.py` 是否报「页面缺文件」；再看开发者工具 Console

## 2. 拍照（相机 + 实时水印）

1. 首页 → 拍照
2. 应该看到：**取景画面里就有水印**（时间/地点/天气/项目），不是拍完才贴上去
3. 允许定位 → 水印里的地点应变成**具体位置**（不是「定位中」）
4. 点「改信息」→ 可以改部位/备注，返回取景
5. 拍一张 → 上传成功提示

看不到水印 → `<camera>` 与 `cover-view` 层级问题（skyline 下 cover-view 必须在 camera 内）
定位失败 → 检查 `requiredPrivateInfos`、系统定位权限、`scope.userLocation`

## 3. 定位兜底

- 拒绝定位权限后拍照 → 水印应显示「未定位」，**不能卡在「定位中」**
- 点「地图选点」→ 能打开选点页，选完水印更新

## 4. 现场记录 → 文书

1. 说一句：「4#楼东侧外架连墙件缺失，出监理通知单」
2. 应该在气泡里看到：步骤（查规范/写文书）+ 最终回答里有**文书卡片**
3. 点卡片 → 能看到文书详情（字段、缺项、出处）

## 5. 巡视记录（这次重点验证表式）

1. 首页 → 巡视记录
2. 选日期范围（比如最近 3 天）→ 生成
3. 应该看到：下载进度 → **直接打开 docx**
4. 打开后核对：
   - 标题「巡视记录」、右上角 `GD-B-214`
   - 表格 **4 行 × 4 列**，合并关系与省统表一致
   - 「巡视的工程部位 / 施工单位 / 巡视时间」已填
   - 「巡视发现的问题及处理情况」有正文、有「巡视监理人员（签名）：」和日期

打不开 docx → 多半是 `wx.openDocument` 前没 `downloadFile` 成功；
下载失败 → 域名不在合法域名列表，或 https 证书有问题

## 6. 记忆

1. 「我的」→ 写一条记忆（比如「整改回复必须附对比图」）→ 确定
2. 刷新小程序 → 这条还在（真写）
3. 点它 → 停用 → 变成「已停用」；再点 → 恢复
4. 「待确认」分段：应能看到模型提议的规矩，点「采纳」后出现在项目规矩里

## 7. 断网/弱网

- 关掉网络后拍照 → 应该提示失败但**不白屏、不丢已填信息**
- 恢复网络重试 → 成功

## 常见故障对照

| 现象 | 先查 |
|---|---|
白屏 | `check-miniapp.py` 页面文件；Console 报错 |
水印不显示 | camera 内是否用 cover-view；skyline 层级 |
定位一直「定位中」 | requiredPrivateInfos / 系统权限 / 兜底文案 |
上传 400 | 上传字段缺 projectId（`check-miniapp.py` 会查） |
生成记录 500 | 服务器 `runtime/bff.log` 最近的 Traceback |
docx 打不开 | downloadFile 域名白名单 / 文件是否真是 docx（PK 头） |
记住的没了 | 看是否调了 POST /memories（而不是只改本地） |
