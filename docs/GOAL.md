# 目标

> 这份文档回答「做这个产品是为了什么」。不写怎么做，只写为什么和做到什么算成功。
> 改这份文档要慎重：它是判断「某个功能该不该做」的唯一标准。

## 一句话

让监理员在工地上**说一句话**，就把该记的记录、该发的通知单、该查的规范一次性做完，
并且事后能追溯「这句话、这份文书、依据哪条规范、谁改的」全部链路。

## 谁在用

| 角色 | 场景 | 他现在怎么做 |
|---|---|---|
监理员（主要） | 巡检发现问题，现场记录 + 查规范 + 开通知单 | 手机拍照 → 回办公室写 Word → 查纸质规范 → 手工编号 |
总监 | 审文书、看整改进度 | 翻微信群、翻文件夹 |
资料员 | 归档、应付检查 | 手工整理台账 |

**核心痛点**：同一个事实要写三遍（现场、文书、台账），且依据经常漏写。

## 产品的三条底线

1. **记录一切** —— 每一轮 AI 做了什么（调了什么工具、读了哪条规范、生成了哪份文书、
   git 提交号）都要留痕，可回放。
2. **零必填** —— 现场信息不全时不允许卡住用户。缺的字段标「待补」，
   事后再补，而不是"请填写完整"。
3. **不阻塞** —— 用户说一句就走，任务在后台跑，回来能看到结果。

## 做到什么算成功

**必须做到（否则不算数）**

- [ ] 现场说一句话（或拍几张照片、或语音+图组合）→ 40 秒内产出可用的监理通知单，依据条号正确
- [ ] 多模态输入不挑形式：纯文字、纯语音、纯照片、任意组合、一次多张，都能用
- [ ] 生成的文书能按项目归档，且每份都有 git 提交可追溯
- [ ] 待补字段能在手机上补齐，补完文书状态自动流转
- [ ] 换人接手时，靠仓库里的文档 + 工作区就能复原现场

**明确不做**

- 不做 CAD/BIM 看图
- 不做造价、进度计划
- 不做视频监控接入
- 不替代签章：AI 只出草稿，签发仍走人工

## 为什么这件事值钱

监理行业的核心成本不是「写字」，是**责任留痕**。
一次检查没留下依据，出了事故就要担责。
所以这个产品的价值不在"AI 会写字"，在**每句话都能追到依据和提交**。
