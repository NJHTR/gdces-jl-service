## 二、找到并修掉的真问题

1. **文书静默不入库**（最严重）
   BFF 只监听 127.0.0.1，MCP 工具容器在桥接网络里 → `fetch failed` →
   agent 手写文件并宣称成功，用户在系统里看不到。已修（绑 0.0.0.0 + host-gateway）。

2. **上传的图永远进第一个项目**
   小程序把 `projectId` 放在 formData，后端只读 query。已修。

3. **`jl-tool` 没进 PATH**（带图慢的真凶之一）
   模型在文件系统里找工具，白花 8 次调用、二十几秒。加软链接后 80s → 24s。

4. **复核员找错目录**
   去 `docs/` 找，文件在 `docs/2026-11-05/`，于是它说"文书不存在"。
   现在直接把绝对路径给它，复核意见变得具体（"受检单位待补，无法送达，文书不成立"）。

5. **瘦身时删掉了"缺项留空、不要追问"**
   它开始连问五个问题而不出稿，违反零必填。已补回。
