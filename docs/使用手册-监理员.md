# 使用手册 · 监理员

> 一页纸。看完就会用，不用记命令。
> 你要是只有 30 秒：**打开小程序 → 说一句现场情况（或拍张照）→ 等它出草稿 → 补缺的字段 → 签发。**

---

## 一、它能干什么

| 你说的话 | 它做什么 |
|---|---|
| 「26#楼南侧外架连墙件缺失，出监理通知单」 | 出一份监理通知单草稿，缺的字段留空 |
| （拍一张带水印的现场照片，说）「这个出通知单」 | 认图上的部位、时间、天气，写进文书 |
| 「这个项目的整改回复要附件对比图」 | 记住这条规矩，以后自动按它写 |
| 「上个月这个部位查过什么」 | 按照片描述把以前的记录找回来 |
| 「外架连墙件有什么规范要求」 | 查规范库，给出条文号和原文 |

**不会做的**：不会替你签字、不会编造条文、不会自己决定整改期限。

---

## 二、三个典型用法

### 1. 现场发现问题，当场出通知单

```
你：26#楼南侧外架连墙件缺失，出监理通知单
它：（约 20~40 秒）监理通知单已出，编号 26#楼南侧外架-01
    依据栏留空（规范库暂无该部位条文）
    缺 5 项：受检单位、整改要求、整改期限、检查结论、签发人
```

**接着做**：点开文书 → 补那 5 项 → 签发。
不用回来告诉它「受检单位是中建八局」——它不需要知道，你直接在手机上填。

### 2. 拍照片 + 一句话

```
你：（拍水印相机照片）这个出通知单
它：认出部位「沙盛四路 ss-w44」、时间、天气，写进文书抬头
```

照片会存进项目相册，以后能按描述查回来。

### 3. 让它记住项目规矩

```
你：记住：整改回复必须附整改前后对比照片
它：好
（以后每次出整改相关文书，它都按这条来）
```

⚠️ **注意**：这条规矩要**过一会儿**才真正进它的长期记忆（它要在你不用的间隙整理）。
当场用，它记得；换个人、换个时间再来，才会从长期记忆里读到。

---

## 三、缺项怎么办（最重要的一条）

**它故意不追问你。**

监理员在工地上没空回答五个问题。所以它的做法是：**先出稿，缺的留空，你在手机上补。**

```
它出稿时就告诉你缺哪几项 → 你在文书详情页填 → 签发
```

**为什么这样设计**：追问会让你在工地站十分钟回消息；留空只让你在坐下时补两分钟。

---

## 四、复核意见是什么

出稿后 20~30 秒，同一条消息下面会出现一张「复核意见」卡。

它是另一路 AI 用不同模型、独立读一遍你的文书，专挑毛病：

```
1.「必须改」受检单位待补，通知无对象、无法签收闭环
2.「必须改」签发人待补，缺签发人即废单
3.「建议改」事由与结论表述重复，可合并
```

**必须改**：不补这条，文书就不成立。
**建议改**：可以不改，但改了更稳。

它**不会自己改你的文书**，只是提意见。

---

## 五、做不到的事（先说清楚，免得等）

| 情况 | 实际表现 |
|---|---|
| 规范库没有对应条文 | 依据栏留空，不会编一个条号给你 |
| 你说的部位很模糊（「这个」） | 它会问或者按照片判断，猜错就改一句话重发 |
| 需要现场测量数据 | 它不编数字，留空 |
| 刚说的规矩立刻换人用 | 要等它整理记忆（隔一段时间） |
| 网络差 | 30 秒~2 分钟不等，慢但不会丢 |

## 六、常见问题

**问：为什么有时候 20 秒就出来，有时候要 1 分钟？**
答：它自己在决定「要不要多查一次规范」「要不要多读一份历史文书」。查得多就慢些，但更准。

**问：我发错了，能撤回吗？**
答：任务列表里有「重试」和「取消」。文书如果已经生成，改字段比重出更快。

**问：它写的文书能直接用吗？**
答：**必须你签字前自己过一遍。** 它负责把格式、部位、依据摆好，判断和责任是你的。

**问：别人能看到我的对话吗？**
答：看不到。你的记忆和会话只跟着你的账号；项目里的文书是全项目共享的（这本来就该共享）。

**问：我说的话它都记？**
答：不是。它每轮结束会让模型判断一次「这句里有没有习惯或规矩」：
- 记：单位写 m³、整改回复要附对比图、旁站结论统一写「经检查符合要求」
- 不记：这一次的部位、数量、日期（这些是记录，不是知识）

同一句话的说法换几次，后台整理时会合并成一条；但**要等它整理**（隔一段时间）。

---

## 七、一句话总结

**它是个手快的实习生：起草快、格式对、会查规范、会挑自己的错；但它不签字、不担责、不懂的地方宁可不写。**
